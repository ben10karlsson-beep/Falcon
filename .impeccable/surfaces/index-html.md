Scope: the whole 169 Poker app (index.html and every view), visual experiment on branch experiment/living-art. Visitor mode: experience, while staying a working study tool.

Audience and job: self-taught 6-max NLHE players studying between sessions; they read ranges, answer trainers and read theory. Every feature and all copy stay; phone width must work.

## Direction contract

Branch experiment/teenage-engineering (supersedes the Op Field contract on this branch only; main keeps Op Field). Visitor mode on this branch: operate (reskin, same layout).

THESIS: 169 Poker as a piece of Teenage Engineering-style hardware, operated like an OP-1/TP-7; refuses both the dark poker-felt app and the op-art poster.
OWN-WORLD: aluminium-grey ground #e3e3df, off-white plates #f5f5f2, black ink #121211; OP-1 knob colours with fixed meaning (orange #ff5a1f raise, blue #4a82ff call, green good); near-black text on every knob colour. Archivo medium for display and body, Martian Mono condensed for numbers, readouts and hand labels. Plates 6px, keys 3px, hairline edges, small key lips. Dark theme is OP-1 black. Layer: css/te.css over css/falcon.css.
STORY: the player reads ranges, answers trainers and reads theory exactly as before, on an interface that feels like a precise instrument.
FIRST VIEWPORT: Preflop ranges, layout unchanged: four-knob logo and key-row tabs, segmented key rails, title, 13x13 grid of key caps whose disc area is frequency, hand plate right.
FORM: brief-pinned (Teenage Engineering); no concept roll ran. Signature move: LED keys (the chosen key pressed in ink with one flat orange LED). Secondary: speaker-grille perforations (gutter field, trainer strip, card backs).
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
